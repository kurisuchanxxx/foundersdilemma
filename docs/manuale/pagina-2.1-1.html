2.1.1

INTRODUZIONE.

Founder’s Dilemma è un business game di startup venturing per l’aula universitaria. Un solo sorgente TypeScript produce tre forme di distribuzione: app desktop Tauri, sito su GitHub Pages e file HTML unico. Il motore di simulazione è separato dall’interfaccia ed è una funzione pura di stato e decisioni (figura 2.1-1).

2.1.2

DESCRIZIONE FUNZIONALE.

Il motore (src/core) riceve lo stato della partita e le decisioni dei team e restituisce il nuovo stato con i report del round. L’interfaccia React legge lo stato da uno store Zustand. Il modulo src/platform salva le partite in IndexedDB e apre i file con i dialoghi nativi su desktop o con il download nel browser. Vite compila lo stesso codice in dist/ e, in modo single, in un file unico. Tre workflow GitHub Actions verificano, pubblicano e impacchettano (figura 2.1-2).

2.1.2.1

Separazione motore-interfaccia.

Nessun file di src/core importa da src/ui: lo stesso motore gira nei test Vitest in Node, nella simulazione Monte Carlo (npm run balance) e nell’app. Il guscio Rust conta 76 righe e serve solo a leggere e scrivere i file scelti dall’utente.

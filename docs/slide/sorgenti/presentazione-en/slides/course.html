Everything needed to propose the module is ready: a recommended format of six three-hour sessions, about 3 ECTS with individual study, learning outcomes in Dublin descriptors, assessment rubrics and the documented simulation model. The session plan also has one-day and two-week variants. The game runs in the browser (also as a single HTML file that works offline and uploads easily to Moodle), on macOS, Windows and Linux.
